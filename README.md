# Guide of Exile – Downloads

Companion-App für Path of Exile 2: Kampagnen-Guide, phasenabhängiger Lootfilter mit Marktpreisen, Handelsanalyse.

**Download:** neueste Version unter [Releases](https://github.com/Zenyth-Gaming/guide-of-exile-releases/releases) → `Guide-of-Exile-Setup-….exe`.
Die App aktualisiert sich danach selbst (App und Guide-Inhalte).

Dieses Repository enthält nur Installer (Releases) und die Inhaltspakete (Branch `content`), keinen Quellcode.

Dieses Produkt ist nicht mit Grinding Gear Games verbunden und wird nicht von ihnen unterstützt.
